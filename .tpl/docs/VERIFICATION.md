# 验收

自动检查：`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`；测试核对双语数据、全部正文素材、15 项实验和挂载路由／语言切换合同。生产实例需检查全部 42 条双语路由返回 200。

浏览器使用内置浏览器，PC 1440×1000、iPad 834×1180、H5 390×844，补测 320px。实际检查菜单、语言、加载更多、FAQ、轮播、动态视频、原生滚动和布局溢出，截图尺寸读取真实解码像素。动效应采样不同时间的状态，静态截图不单独证明还原。

结构化实际结果在 `.tpl/reports/`，仅按已经执行的证据记录。参考站展示字体按要求替换为 Poppins / MiSans；中文按规定字号调整。新增政策页不是原站内容，下载为本地演示，无真实发送。

原站 Fieldstone 文本与结尾协作清单指标不一致；英文保留来源，中文明确注明。素材商业许可未确认。未逐项完成原站三端对照的动效，必须保留未验证说明，不声称逐像素完整复刻。
