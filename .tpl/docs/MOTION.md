# 原站动效清单与实现

参考：https://rhys1.framer.website/ ，观察日期 2026-10-26。使用内置浏览器查看首页、作品列表及详情、关于与探索页，结合公开模块核对参数。全部页面共享导航、联系与页脚；文章与项目保留完整英文结构，中文进行本地化整理。

| 区域 | 触发与节奏 | 实现入口 |
| --- | --- | --- |
| 首屏标题、文字、CTA | 首次进入，弹簧位移；正文与标题按语义组合 | Motion.tsx / HomePage.tsx |
| 首屏圆形徽章 | 360° 线性旋转，12 秒一圈；按住拖动，释放回弹 | Badge |
| 首屏五张卡片 | 初始向上进入，1.2 秒弹簧、按距中心位置错峰；桌面扇形、手机叠放；滚动位移与旋转 | HeroFan / FanCard |
| 卡片拖动与悬浮 | 释放回原位，bounceStiffness 400 / bounceDamping 30；悬浮上移及放大 | FanCard |
| 作品、实验与内容区块 | 进入视口后 opacity 0→1、Y 80→0，0.8 秒弹簧；实验带 rotateX 20→0，1 秒、bounce .2 | Reveal / ExplorationGrid |
| 作品与文章封面 | 悬浮图片缩放，离开恢复；按钮按压缩小 | theme.css |
| 深色关于区 | 照片轮播、4 秒自动切换、悬停与聚焦暂停；手动圆点与左右拖动，spring 200/40 | PhotoCarousel |
| 品牌与实验循环带 | 线性循环，无缝双组；可聚焦，聚焦或悬停暂停，保留原生触控滚动区 | Cards.tsx / theme.css |
| 评价 | 标题按词进入，卡片分别进入；桌面标题 sticky，手机正常流 | SplitTitle / HomePage.tsx |
| 随笔轮播 | 原生横向滚动与吸附，按钮、触控与键盘切换 | NoteGrid |
| 视频与 GIF | 保留 6 个原始 MP4 和原始 GIF；可见时播放，离屏暂停，播放失败有控制器与日志 | Media |
| 菜单 | 0.4 秒无回弹高度展开，导航项错峰；手机背景锁定，Escape 关闭并还原焦点 | Shell.tsx |
| FAQ | 高度 0↔auto 与透明度，0.4 秒弹簧，按钮语义与展开状态 | FAQ |
| 页脚圆贴纸 | 以指针拖动形成折线，前侧裁切、背侧镜像与高光；小范围释放以 710/53 弹簧恢复，超过直径后揭开；键盘按钮提供等价操作 | PeelSticker.tsx |

减少动态效果时停止循环、位移和自动轮播，视频使用控制器。系统覆盖滚动条保持原生；不引入原站 Lenis 滚动引擎，使用浏览器滚动。显示字体依规范使用本地 Poppins / MiSans，而非参考站 Coconat / Clash Display。

## 已验证与限制

独立候选通过三端初态/运行态采样：旋转角度变化，卡片入场，视频播放，轮播第三张选择，循环轨道聚焦暂停；菜单背景锁定、Escape 焦点恢复、FAQ、加载更多、演示下载与贴纸键盘揭开均执行。证据保存在 reports/browser.json。

原站所有页面的三端动效尚未逐项逐帧对照。页面间的原站转场、贴纸翻折的光影与几何、轮播原始自动间隔及拖拽速度曲线存在未完整核对项；当前实现不宣称逐像素或全部动效一致。原站循环带配置 hoverFactor=1，本实现增加聚焦/悬停暂停以便阅读，这是有意的可访问性差异。系统减少动态效果偏好的实际模拟未执行。
