# 许可与来源

本工程是针对公开参考站 https://rhys1.framer.website/ 的学习与演示复刻。参考站作者标示为 Neueframe。页面构成、原始英文案例与素材保留来源，不表示已获得其商业分发许可。

应用实现代码可用于本次授权的开发与验收；不据此推断参考站视觉、文案、照片、GIF 或视频可以商业再分发。`ASSETS.json` 逐项列出参考资源地址；商业发布前应取得授权或替换。`listed=false`、`redistributionAllowed=false`。

字体使用 Poppins 和 MiSans 本地文件，许可与来源说明随字体目录保存。第三方运行库遵守其各自许可证。公开源码地址和包摘要只能证明来源与字节一致性，不能证明素材商业授权。
