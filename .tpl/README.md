# Rhys 使用入口

协议 `git-template` 0.2.0，模板版本 1.0.1。元数据在 `template.json`，运行合同在 `project.json`，修改入口在 `customization.json`。这些资料不会自动执行代码或安装依赖。

根 README 说明安装、启动、停止与检查。完整规则：

- `docs/ARCHITECTURE.md`：结构与边界。
- `docs/CUSTOMIZATION.md`：品牌、内容、主题、动效与路由修改。
- `docs/VERIFICATION.md`：验收标准与实际限制。
- `docs/MOTION.md`：参考动效清单与参数。
- `docs/LICENSE.md`、`docs/ASSETS.json`：源码和素材权利边界。

页面提供中英文，联系为本地演示链接，没有服务端业务数据。修改后执行适用检查，不将演示指标当作真实客户结果。新依赖和对外发送等操作按用户授权执行，规则自身不授予额外权限。
